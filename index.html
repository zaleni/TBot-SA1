WSA Framework

A 3D-centric World-Spatial-Action model

TBot-SA1 is an embodied foundation model that connects instruction-aligned visual planning, causal 3D world modeling, and closed-loop robot action generation.

Existing VLA and WAM policies are often limited by 2D-centric prediction targets. TBot-SA1 introduces World-Spatial-Action (WSA) modeling to learn robot control in a shared 2D-3D latent space, where semantic understanding, spatial world modeling, and physical execution are trained together.

The model reasons about bidirectional causality between robot actions and 3D scene evolution: actions should change the world in physically meaningful ways, and the desired 3D world state should guide the action trajectory.

Highlights

  • The Core: TBot-SA1 learns robot control as World-Spatial-Action modeling, connecting what the instruction means, how the 3D scene should change, and what actions make that change happen.
  • The Difference: Instead of relying on 2D visual prediction alone, the model learns bidirectional 3D world-action causality: actions shape the world, and the intended 3D world guides actions.
  • The Architecture: A Mixture-of-Transformers framework coordinates visual planning, 3D world prediction, and continuous action generation with shared dependency rules.
  • The Fuel: The model is pretrained on 6,000 hours of heterogeneous demonstrations from simulation, real robots, and egocentric human videos.
  • The Output: A fully open-source 3B policy with strong results across RoboTwin2.0, RoboChallenge, and real-world robot manipulation tasks.
